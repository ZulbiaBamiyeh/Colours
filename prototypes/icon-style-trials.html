What you're comparing

Both windows use the same five models. Only the rendering differs:

  • Maple-style: rendered at 32 pixels with three-tone toon shading, outlined in a darker shade of each edge colour, then scaled up with hard pixel edges. Rarity shows as a coloured slot frame.
  • RuneScape-style: rendered smooth at full size with flat-shaded faces, muted colours and a hard drop shadow.
  • Each item is a short recipe of shapes and colours, so the other items in the doc follow the same process, and switching styles changes every icon at once.
